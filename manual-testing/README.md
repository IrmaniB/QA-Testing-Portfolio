# Manual Software Testing Portfolio

This folder contains my hands-on manual software testing work.

## Included File

- `Manual_Software_Testing_Portfolio.xlsx`

## What the Workbook Contains

- **Test Cases** — structured test cases with preconditions, steps, test data, expected results, and priority
- **Execution Log** — actual results, pass/fail status, notes, environment, and linked defects
- **Bug Report Log** — reproduction steps, expected vs. actual results, severity, technical evidence, and supporting documentation
- **Test Summary** — overall execution metrics and major findings
